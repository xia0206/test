# 网页计算器

这是一个使用 HTML、CSS、JavaScript 实现的网页计算器项目。

## 功能

- 加、减、乘、除
- 百分号计算
- 小数计算
- 删除单个字符
- 清空输入
- 键盘输入支持
- 简洁响应式界面

## 文件说明

```text
index.html   页面结构
style.css    页面样式
script.js    计算器逻辑
README.md    项目说明
```

## 使用方式

直接打开 `index.html` 即可使用。

## GitHub Pages 部署

1. 打开仓库 Settings。
2. 进入 Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待部署完成。
